CITYDRIVE CAR RENTAL WEBSITE
BN109 Web and Multimedia Systems — Assignment 2

HOW TO VIEW
Open index.html in any modern web browser. No server, installation or internet
connection is required because the stylesheet and images are stored locally.

REQUIRED PAGES
1. index.html       — Home
2. cars.html        — Find a Car
3. vehicle.html     — Vehicle Details
4. locations.html   — Pickup Locations and Rental Guide
5. gallery.html     — Gallery
6. contact.html     — Contact Us and booking enquiry form
7. thankyou.html    — Enquiry confirmation
8. compliance.html — Development and Compliance

FOLDERS
css/style.css — Shared responsive styling for all pages
images/       — Local royalty-free photographs

FORM NOTE
This is a static educational website. The booking enquiry form uses
action="thankyou.html" and browser validation to demonstrate the required page
flow. It does not send or save personal data.
